# Contributing to FinTrack AI

Thank you for your interest in contributing to FinTrack AI.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/fintrack-ai.git
```

3. Navigate to the project.

```bash
cd fintrack-ai
```

4. Install dependencies.

```bash
pip install -r requirements.txt
```

5. Start the application.

```bash
streamlit run app.py
```

---

## Development Guidelines

- Follow the existing project structure.
- Write clean and readable Python code.
- Keep functions modular and reusable.
- Add comments where appropriate.
- Avoid breaking existing functionality.

---

## Pull Requests

Before submitting a pull request:

- Ensure the application runs without errors.
- Verify all features continue working.
- Keep pull requests focused on a single improvement.
- Update documentation if necessary.

---

## Reporting Bugs

If you discover a bug, please include:

- Operating System
- Python version
- Streamlit version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

## Feature Requests

Feature requests are welcome.

Please describe:

- The problem you're trying to solve.
- Your proposed solution.
- Any alternative approaches considered.

---

## Code Style

- Follow PEP 8.
- Use descriptive variable names.
- Keep functions focused on a single responsibility.
- Remove unused imports and code before submitting.

---

## Questions

If you have questions, feel free to open a GitHub Discussion or create an Issue.

Thank you for helping improve FinTrack AI.
