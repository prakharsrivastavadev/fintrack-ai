# Security Policy

## Supported Versions

The following versions currently receive security updates.

| Version | Supported |
|----------|-----------|
| 3.x | ✅ Yes |
| 2.x | ❌ No |
| 1.x | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** create a public GitHub Issue.

Instead:

1. Describe the vulnerability clearly.
2. Include steps to reproduce the issue.
3. Explain the potential impact.
4. Provide screenshots or logs if applicable.

The report will be reviewed as soon as possible.

---

## Scope

Examples of security issues include:

- Unauthorized access to data
- CSV or file handling vulnerabilities
- Dependency vulnerabilities
- Authentication or authorization issues (if added in future versions)
- Code execution vulnerabilities
- Data corruption issues

---

## Out of Scope

The following are generally not considered security vulnerabilities:

- Typographical errors
- UI or styling issues
- Feature requests
- Performance improvements
- Documentation mistakes

---

## Security Best Practices

Users are encouraged to:

- Keep Python and dependencies updated.
- Install packages only from trusted sources.
- Regularly update Streamlit and Pandas.
- Avoid committing sensitive files such as API keys or personal financial data.
- Keep local data backups when storing financial records.

---

## Disclosure Policy

Security reports will be reviewed responsibly.

If confirmed, the issue will be investigated, fixed, and included in a future release where appropriate.

Thank you for helping keep FinTrack AI secure.
