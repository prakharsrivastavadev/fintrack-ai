# FinTrack AI

An AI-powered personal finance tracker built with Python, Streamlit, Pandas, and Plotly.

## Features

- 📈 Income & expense tracking
- 💰 Savings dashboard
- 📊 Interactive charts
- 🗂 Expense categorization
- 📅 Monthly analytics
- 📤 CSV export
- 🔍 Search and filtering
- 🎨 Clean modern interface

## Tech Stack

- Python 3.11+
- Streamlit
- Pandas
- Plotly

## Project Structure

fintrack-ai/

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
